# Lean formalization

This directory contains the terminal proof entry [PerturbedBoundaryMain.lean](PerturbedBoundaryMain.lean) and build instructions for the three results stated in the manuscript.

The formalization has passed **Lean 4.34.1 compilation** and **native Comparator verification**.

## Build instructions

Download `Lean_Proof_Source.zip` from the [release](https://github.com/Argonaut-Math/argonaut-math-quasi-riemann-boundary/releases/tag/v0.1.5), unpack it, and follow [BUILD.md](BUILD.md) from the unpacked `Lean_Proof` directory. The package contains the complete source overlay, dependency revisions and reconstruction script.

The files displayed here are copies from that package. Use the archive's original directory layout for the full build.
